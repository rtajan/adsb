# ADS-B signal processing tools.

This package provides tools for processing and analyzing Automatic Dependent Surveillance-Broadcast (ADS-B) signals, which are used in aviation for tracking and communication between aircraft and ground stations. The tools include functions for decoding ADS-B messages, extracting relevant information such as aircraft position, velocity, and identification, and visualizing the data.

## Installation
After cloning the repository, you can install the package using pip:

```bash
pip install .
```
